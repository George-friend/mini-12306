# Mini-12306 在线车票服务系统

> 软件工程基础实验课程项目 · 2 人组 · 智能开发平台：DeepSeek Harness · 主力模型：deepseek-v4.1-flash

一个**简化版中国铁路 12306**，面向旅客 / 售票员 / 管理员三类角色，提供实名注册、车次查询、在线购票、在线支付、退票、改签、系统设置的**完整可运行闭环**。
第三方服务（身份证实名认证 / 手机短信 / 银行支付）全部由**本地 Mock 服务**实现，无需任何外部账号即可完整演示。

---

## 快速开始

```powershell
# 1) 安装依赖 + 建库 + 灌入演示数据（首次执行一次，约 1~2 分钟）
npm run setup

# 2) 同时启动后端（:4000）与前端（:5173）
npm run dev

# 3) 浏览器打开
#    http://127.0.0.1:5173
```

## 功能范围

**旅客端**：实名注册（实名核验 + 短信验证码）、登录、乘车人管理、车次查询（按日期/车站/车次类型/席别/时段筛选与排序）、余票与票价展示、下单锁票、在线支付、订单管理、退票（阶梯费率试算）、改签（差价收退）、公告查看、个人资料维护。

**售票窗口**：按订单号 / 证件号 / 手机号 / 姓名检索旅客与订单、代客下单、现金收银出票、代客退票。

**管理后台**：运营概览、车站管理、车次管理、运行日批量生成、票价与定员维护、订单检索、用户冻结与重置密码、公告发布（含晚点/停运联动）、系统参数设置、审计日志、超时订单手动释放。

**明确不做**：真实第三方接口对接、微服务/消息队列/缓存中间件、原生 App 打包、候补购票与联程换乘。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 前端 | React 18 + TypeScript + Vite 5 + Tailwind CSS 3 + React Router 6 |
| 后端 | Node.js + Express 4 + TypeScript + Prisma 6 |
| 数据库 | SQLite（单文件 `apps/api/prisma/dev.db`，16 张表） |
| 安全 | JWT 会话 + RBAC、bcrypt 密码哈希、AES-256-GCM 证件号加密、Zod 入参校验 |
| 一致性 | 数据库事务 + 乐观锁（防超卖）、幂等键、状态机守护、超时订单自动释放 |
| 文档 | Markdown + Mermaid，pandoc 可导出 docx |

## 关键技术点（答辩备查）

| 主题 | 做法 | 证据 |
| --- | --- | --- |
| 防超卖 | 事务内先判定余票，再用「乐观锁 version + 条件更新」扣减；受影响行数为 0 即并发冲突 | 定员压到 3 张后发起 8 个并发下单，恰好 3 笔成功、5 笔被拒，`已售+锁定 ≤ 定员` 恒成立 |
| 支付回调 | Mock 银行收银台构造 payload → HMAC-SHA256 签名 → 回调 `/payments/callback` → 服务端验签 → 结算出票；签名错误返回 7002 | 冒烟测试第 8 项 |
| 幂等 | 下单以 `Idempotency-Key` 唯一列去重；支付回调以支付单状态去重 | 冒烟测试第 7 项 |
| 退票费阶梯 | ≥8 天免收 / 48h~8天 5% / 24~48h 10% / <24h 20%，向上取整到分，最低 2 元 | `apps/api/src/services/ticket.ts` |
| 改签差价 | 补收或退还差价，退差部分按退票费阶梯对差额核收；每张票限改签一次 | 冒烟测试第 10 项 |
| 敏感信息 | 证件号 AES-256-GCM 加密落库 + HMAC 摘要用于检索，界面与日志一律脱敏 | `apps/api/src/lib/crypto.ts` |
| 超时释放 | 惰性检查（查单/支付时就地释放）+ 定时任务（每 60 秒扫描）双保险 | `apps/api/src/routes/orders.ts` |
| 城市级检索 | 输入「北京 → 上海」自动展开为同城全部车站（北京南/北京西 → 上海虹桥/上海），与真实 12306 一致 | `apps/api/src/routes/trains.ts` 的 `resolveStationGroup` |
| 车站选择器 | 聚焦即列出全部 16 个车站，支持站名/城市/拼音/电报码检索与键盘操作 | `apps/web/src/pages/Home.tsx` 的 `StationField` |
| 视觉资产 | 全部为**本地自绘 SVG**（铁轨透视 / 复兴号剪影 / 速度线 / 站牌角标 / 票根卡片 / 24 个线性图标），无外部图片依赖，离线可用 | `apps/web/src/components/{Icon,Decor}.tsx`、`apps/web/public/favicon.svg` |
| 页面截图 | `npm run test:ui -- --gallery` 自动登录各角色并逐页截图到 `assets/ui/`，可直接作为实验报告素材 | `scripts/ui-check.mjs` |
