## 报告是怎么生成的

报告不是另写一份 Word，而是**复制课程模板后往里填内容**：

```powershell
powershell -File report\build-report-doc.ps1
```

脚本做的事：

1. 复制 `实验1-4,6-7的实验报告书模板.doc` → `实验一-实验报告.doc`（**原模板保持不变**）；
2. 读取 `实验一-报告内容.md`，把元信息填入模板表头的信息栏（实验项目名称 / 实验者 / 专业班级 / 组别 / 同组者 / 实验日期）；
3. 把三个部分的正文分别写入模板表格第 4 / 5 / 6 行的合并单元格内：
   - 第 4 行 → 第一部分：实验预习报告
   - 第 5 行 → 第二部分：实验过程记录
   - 第 6 行 → 第三部分：结果与讨论（写在模板自带的**成绩评定表之前**）
4. 正文沿用模板原有字体（宋体 / Times New Roman）与字号（五号 10.5pt、小标题 12pt），段落为单倍行距、段前段后 0；
5. **成绩评定表保持原样**，由教师填写。

> 模板结构：一张 6 行表格 —— 前 3 行是信息栏，第 4/5/6 行分别是三个部分的合并单元格，第 6 行内还嵌有 6×4 的成绩评定表。脚本按这个结构精准写入，不新增、不删除、不改动任何模板元素。

## 提交前必做（3 步）

1. **替换文字占位**：在 `实验一-报告内容.md` 中搜索 `【`，替换为真实姓名、学号、班级、组别、日期等信息。
   共 20 处占位（姓名 4 处、学号/班级/组别/同组者/日期等 16 处）。
2. **替换图片占位**：把本组真实的工作照片与 LLM 交互截图，**保存为同名文件覆盖** `截图/` 下的对应图片（无需改任何文件）。
3. **重新生成**：

```powershell
powershell -File report\build-report-doc.ps1
```

生成完成后可顺便看一眼 Word 里的页数、字数与内嵌图片数，与脚本输出对照。

## 截图是怎么来的

- **UI 原型截图**：`node scripts/ui-check.mjs --report-shots` 用真实浏览器（Chrome 无头 + CDP）自动登录各角色，逐页截取**视口尺寸**（1440×900）截图并直接写入 `截图/` 目录，文件名与报告引用一一对应。
- **工作照片 / LLM 交互截图**：当前为占位图（占位工作照由 `node scripts/make-placeholders.mjs` 生成），需自行替换。
